# Tanishq 22K Gold Price Tracker Agent

An automated GitHub Actions agent that tracks the daily **22 Karat gold rate** per gram from Tanishq every day at **2:00 PM IST**. 

- Sends daily 2:00 PM price summaries via Email and/or SMS.
- Triggers a high-priority notification alert whenever the rate drops below **₹12,750 per gram**.
- Runs fully in the cloud via GitHub Actions ($0 host cost).

---

## 🚀 Setup Instructions

### 1. Create Repository & Upload Files
1. Create a new GitHub repository (public or private).
2. Upload the following files preserving their structure:
   - `tracker.py`
   - `requirements.txt`
   - `README.md`
   - `.github/workflows/gold_tracker.yml`

---

### 2. Configure GitHub Secrets

Go to your repository on GitHub:
**Settings** → **Secrets and variables** → **Actions** → **New repository secret**.

#### For Email Delivery (e.g., Gmail)
| Secret Name | Value Description |
|---|---|
| `EMAIL_USER` | Your full Gmail address (e.g., `you@gmail.com`) |
| `EMAIL_PASS` | Your 16-character **Google App Password** *(see below)* |
| `RECIPIENT_EMAIL` | The email address where you want to receive alerts |

> **How to generate a Gmail App Password:**
> 1. Visit your Google Account → **Security**.
> 2. Enable **2-Step Verification** if not already enabled.
> 3. Search for **App passwords**.
> 4. Create a new app name (e.g., `Gold Tracker`) and copy the 16-character code into `EMAIL_PASS`.

---

#### For SMS Delivery (Optional - Twilio)
If you prefer SMS alerts alongside or instead of email:
| Secret Name | Value Description |
|---|---|
| `TWILIO_ACCOUNT_SID` | Your Twilio Account SID |
| `TWILIO_AUTH_TOKEN` | Your Twilio Auth Token |
| `TWILIO_PHONE_NUMBER` | Your Twilio Virtual Phone Number (with `+`, e.g., `+1234567890`) |
| `RECIPIENT_PHONE` | Your mobile number (with country code, e.g., `+919876543210`) |

*(If Twilio secrets are omitted, the agent automatically skips SMS and sends only Email.)*

---

### 3. Test Running the Agent Immediately
You do not have to wait until 2:00 PM to test:
1. Go to the **Actions** tab in your GitHub repository.
2. Select **Tanishq 22K Gold Rate Agent** from the left sidebar.
3. Click **Run workflow** → select the `main` branch → click the green **Run workflow** button.
4. Review the console logs and verify your inbox or phone for the notification.
